# Source inventory prompt

Read the source list, RFC 0012, current resistance code, and tests. Research
candidate published kayak/canoe resistance datasets. Produce
`striatum/0012-resistance-calibration-source-review/research/SOURCE_INVENTORY.md`.

Required sections:

- candidate table with URL, source type, measured/calculated data, access,
  license/provenance risk, and extraction risk;
- recommendation for which candidates should proceed to review;
- explicit no-go notes for sources that should not calibrate the model.
