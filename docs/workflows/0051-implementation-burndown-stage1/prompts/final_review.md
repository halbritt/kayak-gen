# Final Review Prompt

Read the runbook, RFCs, workflow 0050 decision results, implementation
summaries, review artifacts, findings ledger, remediation summary, changed
files, and validation evidence.

Verify:

- all implemented work is within accepted RFC/workflow 0050 scope;
- blocked items remain blocked;
- no calibrated resistance, validated CFD, real solver success, production
  hosting, design fitness, or safety/seaworthiness claims were introduced;
- review findings were fixed or recorded as non-blocking successors;
- `CHANGELOG.md` and workflow reports are updated;
- `git diff --check` and relevant tests pass or skips are justified.

Publish a final finding artifact and verdict.
